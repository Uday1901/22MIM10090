# 22MIM10090

Full stack notification platform submission.

## Structure

- `logging_middleware` - reusable logging package
- `notification_system_design.md` - staged design notes
- `notification_app_be` - backend API
- `notification_app_fe` - React frontend

## Run Backend

```bash
cd notification_app_be
npm install
copy .env.example .env
npm run dev
```

## Run Frontend

```bash
cd notification_app_fe
npm install
copy .env.example .env
npm run dev
```

The frontend is configured for `http://localhost:3000`.
